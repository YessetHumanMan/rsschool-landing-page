# SimpleFood — Landing Page

Авторский проект для задания **Landing Page** курса RS School.

SimpleFood — адаптивный двухстраничный сайт сервиса доставки еды. Визуальная концепция основана на моём предыдущем проекте [simplefood](https://github.com/YessetHumanMan/simplefood) и переработана под актуальные требования задания.

## Страницы

- `index.html` — главная страница сервиса;
- `catalog.html` — каталог блюд.

## Реализовано в Part 1

- семантическая разметка двух страниц;
- единые header и footer;
- hero и шесть контентных секций на главной странице;
- макет карусели из трёх отзывов;
- пять категорий и десять карточек каталога;
- адаптивная вёрстка от 1440px до 380px;
- светлая и тёмная темы;
- сохранение темы в `localStorage`;
- состояния hover и focus для интерактивных элементов.

## Технологии

- HTML5;
- CSS3;
- JavaScript;
- localStorage.

Проект не использует CSS- и JavaScript-фреймворки, библиотеки компонентов или сторонние библиотеки интерактивности.

## Локальный запуск

```bash
python3 -m http.server 5500
```

После запуска откройте [http://localhost:5500](http://localhost:5500).
